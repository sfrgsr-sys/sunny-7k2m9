Sunny Cycle - installable app files

These files are only the app's code. None of your entries are in them.

1. Upload this whole folder (or this zip) to a free static web host, such as Netlify Drop,
   Cloudflare Pages or GitHub Pages. Pick a site name nobody would guess.
2. On your phone, open the new address in Chrome, tap the three-dot menu, then Install app.
3. Move your entries once: in the old version go to Settings > Copy backup. In the new
   version go to Settings > Restore or import, paste, and tap Add to my data.

Anyone who knows the address could open an empty copy of the tracker, but your entries
stay only in your own phone's storage.
